# Round2Plan Mini Site

This folder is a static mini-site for interview prep.

## Pages

- `index.html` - 5-hour sprint plan
- `architecture.html` - hosted-on-what and connects-to-what cheat sheet
- `model-failures.html` - weak-model mistakes and mitigation playbook
- `skills-and-agents.html` - skills files + multi-agent orchestration recipes

## Local preview

Open `round2plan/index.html` in a browser.

## GitHub Pages publish

1. Push this repository to GitHub.
2. In repository settings: Pages -> Build and deployment.
3. Source: Deploy from a branch.
4. Branch: `main`, folder: `/ (root)`.
5. Save and wait a few minutes.
6. Open `https://<username>.github.io/<repo>/round2plan/`.

If this repo is named `<username>.github.io`, your URL is `https://<username>.github.io/round2plan/`.
